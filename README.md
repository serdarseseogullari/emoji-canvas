# Emoji Canvas

An interactive web application for painting with emojis on a digital canvas.

## Features

- **Emoji Painting** - Click and drag to paint emojis on the canvas
- **Shuffle Mode** - Randomly cycles through all emojis
- **Color Filters** - Select emojis by color category (red, orange, yellow, green, blue, purple, pink, brown)
- **Dark Mode** - Toggle between light and dark themes
- **Performance Optimized** - Spatial grid rendering for smooth performance with thousands of emojis
- **Responsive** - Works on desktop and mobile devices

## Tech Stack

- [Next.js 16](https://nextjs.org/) - React framework
- [React 19](https://react.dev/) - UI library
- [Tailwind CSS](https://tailwindcss.com/) - Styling
- [next-themes](https://github.com/pacocoursey/next-themes) - Dark mode support
- [Lucide React](https://lucide.dev/) - Icons

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
